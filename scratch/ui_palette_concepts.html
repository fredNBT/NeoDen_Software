NeoDen Gerber Viewer — UI direction

Three palette concepts, on the real layout

Each mock reuses the app's actual chrome — menu, toolbar, Board View tabs, Layers panel, PCB canvas, and BOM grid — so you're judging the colors on your own screens, not an abstract palette strip. All three share one type family (IBM Plex) in different cuts, so the family resemblance is intentional; only color and a little weight change between them.

CONCEPT A

Fab Floor

Dark chrome that matches the canvas you already have, instead of a light frame around a dark rectangle. Soldermask green carries every accent; copper amber is reserved for the one row that needs it. Best for long sessions at the bench.

CONCEPT B

Bench Light

A clean daylight chrome closer to Altium/KiCad's light modes — cool near-white panels, a precise circuit-trace blue for actions and the active tab. The canvas stays dark on purpose: that's the one part of a PCB tool every engineer expects to see rendered on black, regardless of app theme.

CONCEPT C

Copper & Flux

Built from the board itself rather than generic UI neutrals: raw FR4 tan for the chrome, copper for every accent. The canvas even swaps the usual soldermask green for a bare-copper board — this is the only concept where the material shifts with the theme, not just the color.
